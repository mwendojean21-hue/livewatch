Déposez ici le fichier livewatch.apk

Chemin exact attendu par le serveur :
static/downloads/livewatch.apk

Le bouton "Télécharger l'APK" dans les Paramètres utilisateur (/settings)
appelle la route /download/apk qui sert ce fichier. Tant que le fichier
n'est pas présent, la route renvoie une erreur 404 propre au lieu d'un lien mort.
